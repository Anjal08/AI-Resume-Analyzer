BACKEND ARCHITECTURE - RESUMIND (AI RESUME ANALYSER)
=====================================================

1. TECH STACK:
   - Runtime: Node.js
   - Framework: Express.js (High performance, minimalist)
   - Database: MongoDB Atlas (Cloud-hosted NoSQL)
   - ODM: Mongoose (For schema validation and typed responses)
   - AI Integration: Groq SDK (Llama 3.3 70B Model) & Google Generative AI (Gemini)
   - Authentication: JWT (JSON Web Tokens) & Google OAuth 2.0

2. CORE MODULES:
   - index.js: The heart of the backend. Handles routing, analysis logic, and streaming.
   - models.js: Defines the data schema for "Users" and "Applications" (history).
   - Middleware: Custom `auth` middleware to verify tokens and protect routes.

3. DATA & FILE FLOW:
   - Multer Storage: Resumes are temporarily stored on the server using diskStorage.
   - PDF Parsing: `pdf-parse` extracts raw text from the uploaded PDF buffer.
   - Sanitization: Regex cleans the extracted text of any non-readable characters.

4. DUAL-PASS AI ANALYSIS (THE CORE INNOVATION):
   - Pass 1 (Deep Analysis): Sends the Resume and JD to Llama 3.3. It performs weighted keyword scoring and the "So What?" test.
   - Pass 2 (Refinement): The results from Pass 1 are sent back to the LLM for "self-correction," ensuring the feedback isn't too harsh or missing technical gaps.
   - RAG & Interview Chat: Stores application details so the chatbot can maintain a "Senior Recruiter" persona and ask context-aware interview questions.

5. INTERVIEW TALKING POINTS:
   - "I implemented a dual-pass AI architecture to ensure the analysis is accurate and actionable, mimicking a real human recruiter's thought process."
   - "The backend supports SSE (Server-Sent Events), allowing it to stream progress status directly to the user during long AI tasks."
   - "I used MongoDB for its flexibility in storing semi-structured AI feedback (JSON objects), allowing for rapid scaling of features."
