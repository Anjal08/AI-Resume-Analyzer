FRONTEND ARCHITECTURE - RESUMIND (AI RESUME ANALYSER)
======================================================

1. TECH STACK:
   - Framework: Next.js 14 (App Router)
   - Styling: Tailwind CSS (Utility-first CSS)
   - Animations: Framer Motion (For smooth transitions and dashboard "wow" factor)
   - Icons: Lucide React
   - Charts: Recharts (For visualizing match scores and skill gaps)
   - API Communication: Axios (With interceptors for JWT handling)

2. CORE COMPONENTS & STRUCTURE:
   - App Router Architecture:
     - layout.js: Defines the global design (Navbar, Theme, Sidebar).
     - page.js: The landing page with features and CTA.
     - dashboard/: Protected route showing user application history.
     - analyze/: The core interface where users upload resumes and view live analysis.
   - State Management: 
     - Leverages React "useState" and "useEffect" for local interaction.
     - Uses Next.js "Context" or custom hooks for global User Auth state.

3. KEY FEATURES & LOGIC:
   - File Upload System: Uses traditional HTML input with Axios "FormData" to stream the PDF to the backend.
   - SSE (Server-Sent Events) Handling: Implements a listener to receive real-time updates from the backend (e.g., "Parsing PDF...", "Analyzing Skills...") to provide a "live" feel.
   - Responsive Dashboard: Built with a mobile-first approach using Tailwind's grid/flex system.
   - Dynamic Results: Renders complex JSON structures from the AI into clean, readable cards, progress bars, and charts.

4. INTERVIEW TALKING POINTS:
   - "I chose Next.js 14 for its optimized routing and performance, ensuring a professional, premium user experience."
   - "I used Framer Motion to create micro-animations that make the platform feel like a modern, enterprise-grade AI dashboard."
   - "The frontend communicates with the Node.js backend using structured API calls, handling JWT tokens securely for user sessions."
